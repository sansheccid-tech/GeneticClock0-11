- Región: D-loop (16,024-576)
- Picos: 16,210 bp, 16,325 bp, 16,440 bp
- Sector 0 (16,300-16,400 bp) - Score 0.92
- Validación: n=1,240, 5-fold
- Performance: Accuracy 0.89, Precision 0.88, Recall 0.90, F1 0.90, AUC 0.93
